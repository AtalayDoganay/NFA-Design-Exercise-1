TO RUN JFLAP YOURSELF
Open nNN.jff, choose Input > Multiple Run, then Load Inputs > nNNt.txt.
Select the final blank row, then click Enter Lambda (or Enter Epsilon) to add the empty-string test.
Click Run Inputs. The first eight tests should accept; the remaining nine should reject.
For the tree examples, choose Input > Step with Closure, enter the string above, and click Step once for each bit.
JFLAP may retain dead configurations in red. Green means an accepting configuration.
